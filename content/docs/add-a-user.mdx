*Available since v2.0.0*

Umami allows you to create separate accounts so that you can host data for friends or clients.

## Roles

User roles and related permissions.

| Role | Permissions |
| --- | --- |
| Admin | All permissions. |
| User | All permissions except admin console. |
| View Only | View only. |

Log into Umami as the administrator and click on the side nav profile button then click **Admin**.

Only **Admin** users can access the **Admin** console.

![image](/images/docs/navbar-settings.png)

Then navigate to **Users** and click on the **Create user** button.

![image](/images/docs/user-create.png)

Fill out the form details and click the **Save** button.

![image](/images/docs/user-create-form.png)

The new account will have its own dashboard and websites separate from the **admin** account.

## Require two-factor authentication

From a user's admin page, you can require [two-factor authentication](/docs/two-factor-authentication) for
that account. The user will be prompted to set it up the next time they log in.
