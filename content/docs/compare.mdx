*Available since v2.12.0*

Umami supports comparing website stats and metrics across previous date ranges. See how your website performs versus the past and if it's
trending in the right direction.

## Parameters

| Parameter | Description |
| --- | --- |
| Previous date range | (required) Comparison date range which can be the previous period or year. |

## Create an insight

### Step 1: Choose a previous date range

- **Previous period**: Same date range from the most recent past period.
- **Previous year**: Same date range last year.

![image](/images/docs/compare-date.png)

If the selected range is still in progress, such as **Today** or **This month**, the stats are compared against the
same elapsed part of the earlier period, rounded down to whole hours. For example, at 2:30 PM, today's stats are
compared against yesterday from midnight to 2:00 PM rather than the whole day. Available since v3.5.0. Earlier
versions compared against the full earlier period.

### Step 2: Run insight

Compare mode will show website stats along with performance changes between the two periods.
The graph will also display **Views** (purple) and **Visitors** (pink) lines from the previous period.

![image](/images/docs/compare-graph.png)

Compare individual metric stats. Each metric displays a percentage change indicator showing how it has changed compared to the previous period. A green indicator means improvement, while red indicates a decline.

![image](/images/docs/compare-metrics.png)
