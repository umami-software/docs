title: Login
description: Log in to Umami with the default admin account, replace the default password, and enable two-factor authentication for extra protection.
---

Your Umami installation will create a default administrator account with the username **admin** and the password **umami**.

![image](/images/docs/login.png)

The first time you log in with the default password, Umami asks you to replace it before you can continue. This is
required since v3.5.0.

## Changing your password

To change your password later, click on the side nav profile button then click **Settings**.

![image](/images/docs/navbar-settings.png)

Then navigate to **Security** and click the **Change password** button. Before v3.5.0, this button was on the
**Profile** page.

You can also enable [two-factor authentication](/docs/two-factor-authentication) from the **Security** page for
extra account protection.
