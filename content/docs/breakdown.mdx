*Available since v2.5.0*

Umami Breakdown allows you to aggregate and view your data in a variety of ways.
Explore your data more extensively through the utilization of segments and filters.

The insight works by segmenting your data into the following metrics.

- **Visitors**
- **Visits**
- **Views**
- **Bounce Rate**
- **Visit Duration**

## Parameters

| Parameter | Description |
| --- | --- |
| Fields | (required) Metric data you want to segment. This defaults to Path and includes all data collected via the tracker script. |
