---
title: Running on Supabase
description: Use a Supabase PostgreSQL database for Umami, with a pooled connection string for the app and a direct connection string for migrations.
---

[Supabase](https://supabase.com/) is an open source Firebase alternative built on the PostgreSQL database.

## Setup

1. Create a project on Supabase with a given name in a region close to where you will be hosting your Umami project.
2. Get the database connection string from the **Settings > Database** page, then scroll to the bottom for the **Connection Pooling** section and copy the **Connection string**.
3. Add `DATABASE_URL` and `DIRECT_DATABASE_URL` to your `.env` file. `DATABASE_URL` uses the pooled connection on port 6543. `DIRECT_DATABASE_URL` uses the session connection on port 5432 and is used for database migrations, which should not go through the transaction pooler. `DIRECT_DATABASE_URL` is supported from v3.2.0.

   ```dotenv
   DATABASE_URL=postgresql://[db-user].[project-ref]:[db-password]@aws-0-[aws-region].pooler.supabase.com:6543/[db-name]?pgbouncer=true&connection_limit=1
   DIRECT_DATABASE_URL=postgresql://[db-user].[project-ref]:[db-password]@aws-0-[aws-region].pooler.supabase.com:5432/[db-name]
   ```

4. You should now be able to build and start Umami (`pnpm build` followed by `pnpm start`). The first build creates the required database tables.
5. Follow the **Quickstart** guide starting from the [Login](/docs/login) step and be sure to change the default password.
