[Koyeb](https://www.koyeb.com) is a developer-friendly serverless platform to deploy apps globally. The platform lets you seamlessly run Docker containers, web apps, and APIs with git-based deployment, native autoscaling, free SSL, a global edge network, and built-in service mesh and discovery.

## Setup

In this guide, you need to have a PostgreSQL database server running and accepting remote connections. If you do not already have a database, you can check out the **Managed databases** section under [Hosting](/docs/guides/hosting).

<Callout title="Database tables">

The Umami Docker image creates the required database tables automatically the first time it starts, along with a default login account with username **admin** and password **umami**. See the [Build the application](/docs/install#build-the-application) section of the Install docs for details.

</Callout>

To deploy Umami, we use the [Koyeb CLI](https://github.com/koyeb/koyeb-cli); you can also perform the setup using the [Koyeb control panel](https://app.koyeb.com).

### Create Koyeb Secrets

Create two Koyeb secrets to securely store your `DATABASE_URL` and `APP_SECRET`. In the terminal execute the following command:

```shell
$ koyeb secret create umami-database-url
Enter your secret: postgresql://<user>:<password>@<host>:<port>/<db-name>?sslmode=require

$ openssl rand -hex 32 | koyeb secret create umami-app-secret --value-from-stdin
```

### Deploy Umami

Once you've created the secrets, you can deploy Umami. In your terminal run the following command to create a new Koyeb App and deploy the Umami service:

```shell
koyeb app init umami --docker docker.umami.is/umami-software/umami:latest --ports 3000:http --routes /:3000 --env DATABASE_URL=@umami-database-url --env APP_SECRET=@umami-app-secret
```

Your Umami service is being deployed. To retrieve the Umami URL run:

```shell
$ koyeb app get umami
ID                                  	NAME     	DOMAINS                         	UPDATED AT
30de8301-05b1-4131-a842-28e608900000	umami   	umami-<YOUR_KOYEB_ORG>.koyeb.app	2021-07-06 11:58:01.143967 +0000 UTC
```

Open the URL to access Umami and follow the **Quickstart** guide starting from the [Login](/docs/login) step.
