---
title: Running on Prisma Postgres
description: Use a Prisma Postgres database for Umami, with a pooled connection string for the app and a direct connection string for migrations.
---

[Prisma Postgres](https://www.prisma.io/postgres?utm_source=umami&utm_medium=docs&utm_campaign=umami_running_on_prisma_postgres) is a managed PostgreSQL service.

## Setup

1. Create a database in the [Prisma Console](https://console.prisma.io/?utm_source=umami&utm_medium=docs&utm_campaign=umami_running_on_prisma_postgres) in a region close to where you will be hosting your Umami project.
   - You can also create a database from the terminal without an account: `npx create-db@latest`. The direct connection string and a claim URL will be printed to the console. The database is deleted after 24 hours unless you open the claim URL and add it to a Prisma account.
2. Get the connection strings. In the Console, select your database, click **Connect to your database**, then **Generate new connection string**, and copy both the pooled and the direct connection string. They share the same credentials and differ only in the hostname: `pooled.db.prisma.io` for the pooled connection and `db.prisma.io` for the direct connection.
   - If you used `create-db`, replace `db.prisma.io` with `pooled.db.prisma.io` in the printed connection string to get the pooled one.
3. Add `DATABASE_URL` to your `.env` file with the pooled connection string. No extra parameters such as `pgbouncer=true` are needed.
   ```text
   DATABASE_URL=postgres://user:passwd@pooled.db.prisma.io:5432/postgres?sslmode=require
   ```
4. Add `DIRECT_DATABASE_URL` to your `.env` file with the direct connection string. Umami uses it to run database migrations, which should not go through the pooler. This is supported from v3.2.0.
   ```text
   DIRECT_DATABASE_URL=postgres://user:passwd@db.prisma.io:5432/postgres?sslmode=require
   ```
5. Build Umami with `pnpm build`. The first build checks the database connection and creates the required tables.
6. Follow the **Quickstart** guide starting from the [Login](/docs/login) step and be sure to change the default password.
