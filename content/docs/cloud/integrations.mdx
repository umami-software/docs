Integrations connect Umami Cloud to the services you already use, so you can see your revenue and search data
alongside your analytics.

| Category | Integrations | What you get |
| --- | --- | --- |
| Payments | Stripe, Paddle, Lemon Squeezy, Dodo Payments, Polar, WooCommerce | Payments and refunds are imported as revenue for a website. See [Payment providers](/docs/cloud/payment-providers). |
| Search | Google Search Console | Google search queries, clicks, and impressions for a website. See [Google Search Console](/docs/cloud/google-search-console). |

<Callout title="Note">

Integrations require a Pro or Business plan. If you downgrade, your existing integrations are still listed so you can
disconnect them, but you can't add or edit integrations.

</Callout>

## Add an integration

Log into Umami and click on the side nav profile button then click **Settings**.

![image](/images/cloud/navbar-settings.png)

Navigate to **Integrations** and click on the **Add integration** button.

![image](/images/cloud/integrations-table.png)

Choose the integration you want to connect.

![image](/images/cloud/integration-add.png)

Fill out the setup form for the integration. Each integration is connected to a single website, which can't be changed
later. To use the same account with more than one website, add a separate integration for each website.

- For payment providers, see [Payment providers](/docs/cloud/payment-providers#add-a-payment-provider).
- For Google Search Console, see [Google Search Console](/docs/cloud/google-search-console#connect-google-search-console).

## Edit or disconnect an integration

Navigate to **Integrations** and click on the **Edit** button or **Disconnect** button next to your integration.

Disconnecting an integration removes the credentials stored in Umami. It doesn't revoke them with the provider. To
revoke access, delete the API key in your provider's dashboard, or remove Umami from your Google account's third-party
access.
